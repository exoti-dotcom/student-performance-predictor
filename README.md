# Student Performance Predictor

A beginner machine learning project built using Python and Scikit-learn to predict student performance based on study hours and attendance.

## Features
- Data preprocessing using Pandas
- Linear Regression model
- Prediction system
- Data visualization using Matplotlib
- Model saving using Joblib

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- NumPy

## How to Run

```bash
pip install -r requirements.txt
python main.py
